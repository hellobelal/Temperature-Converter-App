🌡️ Temperature Converter App

A simple Flutter app to convert temperature between Celsius and Fahrenheit.

Features
Enter a temperature in a TextField
Choose conversion type using a DropdownButton (°C → °F or °F → °C)
Press Calculate to see the result (2 decimal places)
Validation: shows an error for empty or non-numeric input
Colorful UI, custom app icon, and an About page
Formulas
Celsius to Fahrenheit: F = (C × 9/5) + 32
Fahrenheit to Celsius: C = (F − 32) × 5/9
Run
bash
flutter pub get
flutter run
